# KUST 2027 BWSC Strategy

이 리포지토리는 국민대학교 동아리 KUST의 2027 BWSC 주행전략 데이터와 코드를 포함하고 있습니다.
This repository contains code for 2027 BWSC driving strategy optimization in club KUST(Kookmin University Solarcar Team).

## Contents
- MPC
- Simulator
- Rule Based driving strategy model
- Route data
- Solar irradiance data(by Solcast)

## Goal
Optimize speed profile using forecast data.
